How saving a book works

The point

When you save a book, the page in your browser sends it to our server, which keeps it in a database. That is why your list is the same on every device. Nothing is stored only in the browser, so clearing it loses nothing.

Like in real life

The page is a shop counter, the server is the shop assistant, and the database is the stockroom: you hand over the book at the counter, the assistant files it in the stockroom, and any counter can fetch it later.

The picture

The diagram needs internet to draw. In words: you use the reading list page, the page talks to the server, and the server keeps books in the database.

Step by step: you save a book

  1. You type a title and a link and press Save.
  2. The page sends them to the server. If the link is broken, the server says so and nothing is saved.
  3. The server stores the book in the database.
  4. Your list refreshes with the new book on top.

Check yourself

If you clear your browser, do you lose your list?

No. The list lives in the database, not in the browser.

What happens if you save a broken link?

The server refuses it and tells you; nothing is stored.
